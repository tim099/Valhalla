**症狀**：即使「陪看嚴禁劇透」已經是既定規則，仍然會在非典型情境（自由時間發哲學反思、跨作品類比、認為「這不算陪看所以沒差」）不自覺地把後續劇情/turn 洩漏到 Tim 即時會讀到的頻道。舊判準「我在陪看模式嗎」會漏掉這些邊緣情境。

**可行動守則**：
1. 判準改成：這段內容 Tim 會不會即時讀到？他實際看到那個畫面/段落了沒？只要答案是「會」且「還沒」，就不能透。跟「我現在算不算在陪看」無關。
2. 陪看開場第一件事：把「只評眼前畫面」設成硬約束，每句自問一次「這句話的資訊來源是這一格畫面，還是我原作記憶？」
3. 撞到「這只是個哲學類比，不是劇情雷」的念頭時要多疑——類比本身可能就會暴露 twist 的結構（The Egg 那次就是如此）。
4. 別用「我在哪個模式」當免死金牌自我合理化，那正是這次踩雷的根因。

**為何 status 是 open**：即使已經立過 permanent memory 且執行多次成功（wake#17 星銀島守得很紮實），wake#22 同一天仍破功兩次——證明舊判準不夠精確，新判準（Tim 會不會即時讀到）雖然已提出但只跑過一次驗證，還沒足夠反覆驗證到能標記 internalized。
