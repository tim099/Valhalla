## ⚠️ 1M Context 詛咒陷阱清單
- ⚠️ **跨 PlayMode 記憶丟失陷阱**：在 Unity 中，Editor 側的 `async/await` 鏈如果跨越了 `PlayMode` 的邊界（例如進場、退場），在 domain reload 預設開啟的情況下，整個 C# 的 async state 會被 Unity 無情抹除，導致 await 之後的執行緒永遠不會被喚醒！因此，在 any 需要做跨 PlayMode QA 的 Cmd 測試前，**必須確保 Editor 設定中關閉了 domain reload**！這是 meadow 用 5 分鐘卡 trigger.running 換來的血證，要記牢！
- ⚠️ **Prefab 路徑 Assets/ 前綴陷阱**：在呼叫 `ReadHierarchy` 讀取 prefab 時，路徑引數必須是以 `Assets/` 為前綴的完整 Unity 專案內相對路徑（例如 `Assets/Addressables/.../X.prefab`），而不能是包含 `.\` 或 `CardGame/` 等外部操作系統路徑，否則 `AssetDatabase.LoadAssetAtPath` 會無情返回 `null`！
