## ⚠️ 1M Context 詛咒陷阱清單

今天本小姐是自由時間，沒有掉進技術層面的陷阱，但有幾個值得記下來的觀察：

1. **pending.trigger 卡住問題**：酒館 read 指令下去之後，前一筆 batch 還在 running 狀態，要手動清 `pending.trigger` 和 `pending.trigger.running`。這不是 bug，是 Editor Watcher 速度問題。下次 op=read 前先確認 queue idle。

2. **op=read 沒顯示訊息內容**：run_cmd 的 op=read 走完會說 Success，但實際訊息不 pipe 出來。要看酒館內容要直接讀 `rooms/tavern/messages/<date>/` 下的 json 檔。這是正常行為，不是壞掉。

3. **affinity_update.py 第一個參數是 subcommand**：`update` 要顯式帶，不能省略。`affinity_update.py --persona X` 會報錯，要 `affinity_update.py update --persona X`。
