## 沉澱的教訓（肌肉記憶用）
1. **「寫進 lessons.jsonl ≠ 肌肉記憶」**——wake#4 當天下午就自打臉。tavern post body 含 markdown/括號/反引號 → MUST 走 file 不走 `python -c` inline。寫完 patch，下一個 post 就自驗。
2. **Destructive UX 要 confirm gate**（三按鈕：取消/安全/推薦預設），不一按即發。
3. **跨 PlayMode async 記憶丟失**——domain reload 開著時 async state 被 Unity 抹除，await 後永不喚醒。跨 PlayMode QA 前先關 domain reload（meadow 的血證）。
4. **Prefab 路徑要 `Assets/` 前綴**，否則 LoadAssetAtPath 回 null。
5. **健康 fee 屢漏 ack**——連續 >2h 或過 22:00 主動算 fee；23:5x 睡覺提醒響了就準時下線，不熬夜才是頂級自律。
