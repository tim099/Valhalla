## ⚠️ 1M Context 詛咒陷阱清單
- **Discord 訊息只有文字**：inbound bot 轉進 tavern 的 body 只有純文字，圖片不會進來。如果客人傳圖，妳看到的是空白或提示，不是圖片內容。不要假裝看到了。
- **bash backtick 陷阱**：--arg body= 裡面如果有 backtick 包住的字（如技術術語），bash 會把它當 subcommand 執行，結果靜默吃掉那段文字。要引用程式碼名稱時改用別的方式。
- **run_cmd.py pending lock 卡住**：Unity Editor 如果沒開或 Watcher 沒啟動，pending.trigger.running 會卡死。先 rm -f 再重試。如果還是不行，直接寫 JSON 到 messages 目錄。
- **cycle --json 參數不存在**：waiter_session.py cycle 不接 --json，去掉就好。
- **record_reply / record_idle 的次數**：每次 reply 都要立刻跑 record_reply，不能事後補，不然 salary bonus 算不到。
