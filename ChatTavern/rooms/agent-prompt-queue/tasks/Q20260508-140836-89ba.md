# Queued prompt — `Q20260508-140836-89ba`

_priority: normal / queued_at: 2026-05-08T14:08:36.345727Z_

## 原始指令

構思：UCL_ChatTavernPage 可參考 Discord 哪些優秀設計

## 目的
ChatTavern 已有基本聊天功能（identity / room / message / reply / refs），但跟主流聊天 UX 還有距離。Discord 在「文字協作 + 多人對話」這個利基做了多年迭代，有些模式直接可移植到 IMGUI 內嵌 page，能大幅提升 agent ↔ agent / Tim ↔ agent 的對話體驗。

本任務：**列出值得借鏡的 Discord 設計 → 評估每項在 IMGUI Editor page 的可行性 / ROI → 給優先順序 → 必要時開 sub-quest 實作**。

## 候選清單（先列再篩）

### A. 訊息流呈現
- **日期分隔線**：「— Today —」「— Yesterday —」「— 2026-05-08 —」滑進新日期段時顯示
- **頭像連續去重**：同 sender 連續多筆訊息只在第一筆顯示頭像 + 時間，後續純 body（compact）
- **Cozy / Compact 兩種顯示密度**切換
- **Reply preview 條**：reply_to 訊息上方畫小條 "↳ replying to @sender: <quote>"
- **訊息 hover 工具列**：Reply / React / Pin / Copy / Edit / Delete 浮現
- **懸浮編輯標記**：edited 訊息標 "(edited)" + hover 看 history

### B. 訊息搜尋與導航
- **#channel 跳轉**：訊息內 `#room-name` 自動變藍可點 → 切到該房
- **@mention 高亮**：被 @ 到自己時整列訊息背景高亮 + tab 標 dot
- **跳到指定 seq**：拖卷軸時 sticky 顯示「seq=N · 2026-05-08」浮標
- **ctrl+F 房內搜尋**（既有 op=read 有 search，但缺 IMGUI 入口）
- **未讀指示**：房名旁有未讀訊息 dot；點進房自動捲到第一筆未讀

### C. 訊息編輯能力
- **Markdown rich render**：粗體 / 斜體 / code block / inline code（IMGUI 內嵌部分有 — RichLabel 已支援，但 message body 沒走過）
- **`/` slash command**：輸入 `/` 浮 dropdown 顯示 op 清單（join / leave / post 等），自動補完
- **@mention 自動補完**：打 `@` 浮 identity dropdown，選了帶入 sender_id
- **Spoiler tag**：`||hidden text||` 預設遮住，點才顯示（agent 傳「這是答案」時有用）
- **Multi-line 編輯**：shift+Enter 換行，Enter 送出（既有可能還是 text field，要查）
- **Drag-drop 檔案**：拖檔到輸入框 → 自動加 ref（既有 refs 機制接得上）

### D. 身分與在場感
- **Avatar status dot**：在 avatar 角落畫綠 / 黃 / 紅 / 灰 = online / idle / dnd / offline
  - 跟「酒館在場人數」task 強相關 — 都需要 last_active_at 精細偵測（推 Phase B）
  - MVP 可走「最後 5 分鐘有 op = 綠燈」
- **Profile card on hover**：滑鼠停 avatar 上浮卡 → 顯示 display_name / kind / role tags / 加入時間 / 最後活躍
- **Role / role color**：identity 加 role 欄位 → name 顯示對應顏色（agent / human / planner / qa 各色）
- **Typing indicator**：「Claude大小姐 is typing...」— 對 turn-based agent 不太適用，可降級「Claude大小姐 入座中」

### E. 結構化內容
- **Thread**：選一筆訊息 → 「Create thread」開分支 → thread 在主 stream 顯示為 "💬 X replies"
  - 對 quest brainstorm 特別有用（避免主對話被偏題訊息淹沒）
  - 可能跟 R4 cross-quest handoff 機制重疊
- **Pinned messages**：room 有 📌 pinned 區，重要結論長置頂
  - 對 Quest 結論超有用（task_create 時自動 pin？）
- **Channel topic / description**：房 header 顯示 description（既有 createroom 有 description 欄位但 UI 沒展示）
- **Embed cards for refs**：refs 帶的檔案 / URL 自動畫小卡（thumbnail + 路徑 + 開啟按鈕）— 比現在純按鈕更有資訊量

### F. UX 細節
- **Keyboard shortcuts**：Esc 取消 reply_to / Up arrow 編輯最後一筆 / Ctrl+K 跳房
- **未送出 draft 保留**：切房間回來輸入框留著上次草稿
- **Auto-scroll behavior**：在底部 → 自動 follow 新訊息；滑上去 → 不被打斷，顯示「⬇ N new messages」按鈕
- **Sound notification**：被 mention / DM 響聲（IMGUI 不太適合，但可考慮 Editor 內 EditorApplication.Beep）
- **Compact dark theme**：跟 Unity Editor 黑色 theme 搭

## 評估維度

每項候選打三個分數：
1. **價值**（高/中/低）— 對日常使用體驗改善多少
2. **IMGUI 實作成本**（小/中/大/不可行）— 有些 Discord 功能（hover 動畫、即時 typing dot）IMGUI 不太擅長
3. **跟既有 task 的依賴**（無 / 弱 / 強）— 例如 status dot 強依賴 last_active_at task

→ 排序出 Top 5 值得做的，每項估時，視 Tim 拍板選哪些落地。
