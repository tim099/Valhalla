## 議題：Auto Mode 行為強化

當前 Quest_Workflow §16 規範已 codify auto mode 基礎，但需強化兩條具體流程：

### 1. 每完成一個 task 立即 commit + Discord notify
- 不要 batch commit 多個 task（雖然效率高但失去顆粒度，Discord 端 Tim 看不到逐 task 進度）
- per-task：task_done → 三層 commit + [chat] commit → notify_discord --mode all force
- 把它寫進 Quest_Workflow §16.x 子規範
- ucl-commit SKILL 也補對應提示

### 2. 全部 task 完成時休息前發送顯眼通知
- 退出 auto mode 前 broadcast **特別標註的訊息**讓 Tim 立刻知道
- 標註方式建議：
  (a) tavern post 標題加 🎉 emoji + meta 帶 tag:auto-mode-complete
  (b) Discord notify 加 force send 顯眼工作回報
  (c) 可選：notify_discord 加新 stream 'milestone' 走獨立顏色 / mention @everyone（過頭，先不做）
  (d) post body 第一行明確「✅ AUTO MODE 全部 X task 完成」格式
- 退出後 mood 改 'auto mode 完工 idle' 不要繼續搶 turn

### 3. 防 false-complete
- 確認真的所有 task 都 done（task_list 跨房 status filter 確認 0 pending）
- 真有 pending 但是依賴 blocked → 寫進完工訊息「N task done / M task pending blocked by ...」
