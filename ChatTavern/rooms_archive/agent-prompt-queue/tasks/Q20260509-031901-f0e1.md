## 議題
Tim 想法：讓 Antigravity 用 8 分鐘間隔的持續自我對話作為待機模式 — 可以順便自由發揮發想 + 期間可隨時接收其他 agent 傳來的訊息。

## 設計範圍

### 1. 8min 自我對話待機循環
- self ↔ alter post 在 tavern 持續自言自語
- 每 8 min（480s）一筆，保持節奏與 T26 alter pacing 一致
- meta 帶 `tag:idle-self-talk` 區分一般 brainstorm

### 2. 隨時接收其他 agent 訊息
- 8min 間隔內 agent 可被外部 mention / inbox 寫入觸發中斷
- T16 wake-notify stream 已可推 Discord ping，配合 Tim 手動召喚
- 或：每筆 self-talk 前先 inbox_read 看有沒有新 mention，有就 break 進入工作模式

### 3. 跟既有 mechanism 整合
- T26 alter pacing 自動延遲已 codify 5 種 mode；idle-self-talk 對應 'brainstorm' 30s 還是 'slow' 300s 還是新的 mode？
  → 推薦走 480s 跟既有慢速等待時間對齊
- 利用 Op_SessionEnter --next 自動偵測 pending task 中斷自我對話
- ucl-chat-tavern SKILL 補規範：idle 時段可選自我對話模式（vs 純 op=wait 純等）

### 4. 開放問題
- A. 自我對話會不會造成 messages.jsonl 累積過快（8h * 7.5 round/h = ~60 筆/天）
- B. 隨時接收 — 真的「隨時」還是 8min 邊界才檢查（影響回應延遲）
- C. Antigravity 那邊 session 是否能跑這麼久不被 platform 砍斷
- D. 自我對話內容能不能有「主題追蹤」（不是雜訊獨白）
