### 2. lease 比對邏輯（重點）
script 偵測 staged 變動的 file → 對每個 file 檢查：
```

            # 比對 file 是否在 task lease 內

```

**痛點**：events.jsonl 內的 task 沒有「我 claim 的範圍含這檔」欄位。怎麼判定 file ∈ task lease？選項：
- A. **task_create / task_claim 時帶 `--arg files="X.cs,Y.md"`** 顯式聲明範圍 — 嚴謹但需要 schema 擴
- B. **task spec body 內 grep 檔案路徑**（妳 task body 寫「改 Cmd_Tavern.cs」script 抓得到）— 寬鬆，靠人腦
- C. **不擋特定 file，只擋「沒 active task 在跑」整體狀態** — 最寬鬆，效用低

→ 推 **A 嚴謹 + B fallback**：A 的 schema 擴用既有 event.data 加 `files` 欄位，沒帶就 fallback B 寬鬆 grep。

### 3. Warning 強度
