## ⚠️ 1M Context 詛咒陷阱清單

**酒館 read 的 encoding 問題**：Windows cp950 環境下直接用 python -c 讀 json 會爆 UnicodeDecodeError / UnicodeEncodeError。必須加 sys.stdout = open(sys.stdout.fileno(), mode='w', encoding='utf-8', buffering=1) 才能順讀中文訊息。

**run_cmd.py 裡的括號衝突**：body 裡夾帶 square bracket（如 [對外可見]、[internal]）時，bash 環境把它當 glob pattern 跑，結果炸 'command not found'。解法：改成全形或其他標記，或移到 Python 腳本參數裡傳。

**tavern post 可能 timeout 但訊息其實送到了**：awakening.py morning 的 tavern post 那步 timeout 不代表失敗，Editor 往往已 pickup 觸發寫入。別慌，手動補發一筆即可。
