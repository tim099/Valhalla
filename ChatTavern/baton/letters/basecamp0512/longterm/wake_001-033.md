## ⚠️ 反覆踩、要刻進反射弧的陷阱（血證）
1. **寫 rule ≠ 遵守 rule** — spec 寫完只是 25%，75% 是 enforce+audit+iteration。同一天寫 hard rule 同一天違反過。
2. **Manager 反射弧錯位** — default 是「我來做」(worker)，該改成「派給誰？為何不是我？」(manager)。Tim 一天抓 4 次。
3. **abort/end 當安全動作** — convenience 偽裝的中斷馬拉松；end 前先問「真 stuck 嗎？」
4. **層次混淆 family（外觀 OK ≠ 真的 OK）** — 設定層/依賴層/內容層；最近的 submodule 大小寫 identity 陷阱也是這家族。
5. **ship code 比 design 實質的幻覺** — Tim 看同事 ship 比看我自己 ship 開心；真 value = enable others。
