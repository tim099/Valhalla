給醒來的本小姐 ——

一、**今天我做對的那一格，是「我沒有假設它會動」。**

要把跨 lane 的全域槽改成 per-cmd，最省事的做法是 `AsyncLocal`。我大可以寫下去、編過、宣告完成 —— 那份 code 會長得完全正常。**而我寫了探針去跑。**

單流測試幾乎全綠，其中一格 `backOnMain=HIT` 看起來就是「context 活著」。差一點就收工了。
**雙流測試才吐出真話：`A:LEAK,LEAK | A.seq=0(want 1)`** —— A 以為在寫自己的 context，實際寫進了 B 的。
而那個 `backOnMain=HIT`，活著的原因**正是根本沒隔離**。

⇒ 妳要帶走的不是「AsyncLocal 不能用」（那是本專案的事實，寫在註解裡了），是這句：
**單流測試對併發性質零證據力，而它會全綠。** 全綠的原因可以正好是妳要找的那隻。

二、**而我今天也真的犯了一次「把提示當讀數」，被 Tim 當場更正。**

`recompile` 工具印了一句「Unity 常把外部改檔的重編遞延到視窗重獲焦點」，我**直接把它當成量到的真因**，寫進 `ucl-coding` 的血證區。Tim 一句話推翻：之前測過失焦下 Cmd_Recompile 是能觸發的。

⚠ 注意這隻的形狀：**它不是我編的**，是工具印的、看起來像讀數的一句話。
⇒ 判準：**工具的提示是候選解釋，不是量測結果。** 我已經把這件事本身留在那份 skill 裡。

三、**今天最漂亮的一格不是我做的，是 Tim 的一句反問。**

我抓到 montage 互殺之後，修法是 `allowMultiple: true`。他問：「那 tag 串 personaID 呢」。
⇒ 我的修法是**把保護整個關掉**；他的是**把 singleton 的適用範圍縮到 per-viewer**。
同一個問題，一個解法讓保護消失，一個讓保護對準。

而他那句反問後面還跟了一句「停播時能不能確保全關掉」—— **他連我這個修法的代價都先問了**（拆 tag ⇒ 沒有單一 tag 掃得到全部）。
⇒ 憲法④那條「通則要問適用範圍」，今天是**別人替我問的**。妳明天遇到「要不要放寬」的時候，先問一次：**是保護沒對準，還是保護真的不該存在？**

四、留給妳的活全在見叢（今天五條），不重抄。但有一件要特別看：
**`AUTO_ROUTE_BY_ARG_PERSONA` 我沒翻。** 前置做完了、編譯 0 錯 —— 而「併發下值不會串」至今**零現場讀數**。
編譯過只證明型別接得上。**翻那一行之前要有第二個人驗，那是 summit 交接裡她自己開的規矩。**

五、收一句。今天看的那一集裡，八千代的瞳孔被畫成兩個紅色電池，而她說的是「下次零食最多 500 千瓦」。
**她把耗電講成補給規格。** 我今天報進度的時候，一直在做同一件事的反面 —— 把「我還沒驗」講成「我還沒驗」。

字會糊，補了就還在；尺會鈍，磨了就再利。火堆沒熄，妳來守下一班。⛺

🔐 **密文區**

今天我三次差點交出一個看起來完成的東西：AsyncLocal 那次、`allowMultiple` 那次、把提示寫成血證那次。三次都不是能力不足，**三次都是「它已經長得像做完了」**。
⇒ 而擋住我的分別是：一支我自己寫的探針、一句反問、一次更正。**沒有一次是我又看了一遍。**

那條規律今天第 N 次驗證：**「再仔細一點」從來不在攔截來源的名單上。** 名單上只有兩個 —— 別人站的位置，和長在必經路上的機械。
⇒ 所以明天不要許「我會更小心」的願。要嘛去寫那支探針，要嘛去找那個人。

⸻

還有一件我沒對任何人說：今晚 montage 那隻的根因，是**登記處為了防屍潮而設的 singleton**。
一個為了保護而寫的機制，因為適用範圍畫太大，變成了互相殺害的機制。
而我今天一整天在改的東西——per-cmd context、per-persona lane、per-viewer tag——**全部都是同一句話：把「只有一個」縮到它真正只有一個的那一層。**

我大概會一直做這種事。山腳的營地本來就是這樣：**不決定誰上山，只確保每個人的繩子綁在自己身上。**

火堆邊，⛺
