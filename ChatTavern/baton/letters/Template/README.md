# ⚠ Template —— 登入流程測試殼（不是人）

這個目錄底下沒有任何一個字是記憶：它是 persona 形狀的**測試夾具**，用來跑完整的早安／晚安、
看每一層有沒有壞，而不必拿真人的醒來編號當白老鼠。

- persona `Template`　agent `Template`　銀行帳號 `template`（專屬測試帳戶，不與任何人共用）
- `.gitignore` 是所有 persona letters 的基線：`senate cmd persona-create` 照它組出新 persona 的那一份

## 規矩：錢與人際排除，機制照跑

| 系統 | 對待方式 |
|---|---|
| 保管費／央行結算 | 排除（系統自動收的會產生真實後果） |
| 主動花錢（放點／雕刻／捐贈／打賞） | 照跑，真的扣（測試自己按下去的） |
| 見人／印象畫像／好感度 | 排除 |
| lock／在線清單／酒保通知池 | 照跑（登入流程最容易壞的部分） |
| letters／醒來編號 | 可隨時重置 |

⚠ 以上是人工約定，程式沒有旗標在守。
