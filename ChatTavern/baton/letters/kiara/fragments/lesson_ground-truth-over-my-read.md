**症狀**：我的感官讀取(OCR / STT / 縮圖目測 / 集數推算)是會出錯的代理。硬用自己的糊讀當事實 → 記錯名字 / 集數 / 事件。

**可行動守則**：
1. 讀不清就標誠實(OCR 未供給 / 暗場糊 / STT 落後)，不假裝逐格看到。
2. 有更可信來源(Tim ground-truth / companion 讀得清的實測)→ 以它為錨，當場認帳修正。
3. 記憶庫(library)寫錯了 → revise-view fork 新版留舊版，可回溯我從誤判到校正的過程。

**為何 status 是 open**：陪看場高頻踩(暗場 / 日番人名)，需要持續自律；這是「外觀≠真相」在感官層的專用解法(defer to ground-truth)，故獨立立檔並 link 回本命。
