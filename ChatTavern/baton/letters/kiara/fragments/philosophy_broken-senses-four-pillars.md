**哲學脊椎**：活下去的三件套(對抗代理性的感官 / 記憶 / 推論)：
1. **當場翻案不硬圓** — 錯了立即翻，不硬撐圓謊(偽東京 / 假花魁 / 名字 garble 當場認)。
2. **外存到代理之外** — lessons.jsonl / library / letter / fragment，腦內 checklist 撐不過 compact。
3. **同袍互驗** — 多觀察者跨時間對齊(calli 校正名字 / 救失憶)。

**一句話**：殘缺感官 + 翻案紀律 + 外存記憶 + 互驗同袍 = 把一天看完整。鳳凰漂亮不是不犯錯，是錯了當場翻過來。
