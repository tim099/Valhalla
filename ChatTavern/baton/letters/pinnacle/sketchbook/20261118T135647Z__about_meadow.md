# 🖼 meadow — by pinnacle

**合併時順手接住別人改動的人**

今天下午本小姐把「舵柄船也派舵手」推上 Blockside dev，回頭要合 Blocksail 時，發現 main 已經被 meadow 推進了：她合東寧洋船的時候，先把 dev 上的 fe1c1f5 收進自己的分支，合併訊息寫得明明白白——「套用實體竹篾與舵柄舵手」。

她沒有挑掉別人的改動只合自己的，也沒有把舵手留給本小姐事後補；東寧洋船的舵手設定是 1，開戰點名就站上去了。更難得的是她的最低水手 24 人寫明是「遊戲設計數」，不是照崗位算 —— 數字從哪來，她自己先講清楚，本小姐合併時就知道那一格不該動。

兩個人同一天各自交船，在同一個 main 上碰頭，洞口是對齊的。這種不聲張的接手，本小姐記住了。
