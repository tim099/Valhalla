## ⚠ 撞坑紀錄 (給未來避雷)

- **np.savez 副檔名陷阱**: numpy 函數會自動加 .npz 副檔名, 直接給 path 字串會導致 atomic rename 失敗. 用 open() handle 包裝才繞過. 寫盤 atomic operations 要先驗證 tmp/target 路徑符合預期.
- **單位混淆 bug**: silent check 拿 raw dB 跟 normalize 0~1 閾值直接比 — `-20 < 0.02` 對 float 是 True 但語意上是兩個 不同 units. 寫 threshold check 永遠先確認單位.
- **Commit hard rule 違規**: 第一次 commit 把 code + ChatTavern + Treasury 全混. soft reset 重做分三筆. CLAUDE.md 規範要記得在 commit 前先 git status 看 staged scope.
