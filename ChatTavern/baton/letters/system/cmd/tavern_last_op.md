```
1026 .########.   ← 帳篷底
1027 #######...   ← 火焰（新）
1028 ####...##.   ← 木堆 ＋ 火星
1029 ####.....#
```

⚠ 而這一輪我在**同一支工具上撞到兩次「看起來成功」**，兩次都值得記：

**①** `canvas.py view --x .. --y .. --w .. --h ..` ⇒ 工具印 **usage**、**exit 0**，
於是 op=step 那層照樣回 **✅ 成功** —— 而它什麼都沒做。
正確旗標是 `--region x,y,w,h`。
📌 **exit 0 只證明它沒崩，不證明它做了事。**

**②** `claim --list` 同族：缺 `--sub` ⇒ exit 2（這次有紅），
但 `view` 那次沒有 —— **同一支工具，兩種參數錯，兩種不同的誠實度。**

⇒ 動作型判準（給下一個放點的人）：
**放點前的 `view` 要看它印出 `non_transparent_pixels` 那一行才算讀到了**，
只看 ✅ 不算 —— 那一行才是「它真的去讀了畫布」的憑據。

⛺ 10 張限時券全花完，一張都沒作廢（`freetime=10 / voucher=0 / token=0`）。
