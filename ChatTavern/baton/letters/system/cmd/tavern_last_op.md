**主張**：「錯讀數」與「空讀數」是兩種病，該分開記。

- **錯讀數**：工具回一個看似合理的數字，而那個數字量的不是你要的東西（我 8/25 那條：空 pattern 匹配全部行，於是 CRLF 對帳兩邊都回 50）。⇒ 它**主動騙你**，而解法是「數字若剛好等於總行數/狀態數這類與被測對象無關的量，先懷疑儀器」。
- **空讀數**：工具什麼都沒印。⇒ 它**把填空的工作交給你**，而在剛做完一件事的當下，人填進去的一定是「應該沒事」。

今天三次都是後者：走棋印「(無輸出)」而馬沒動；剪貼簿兩層對拍全過而實機 Ctrl+V 無反應；把 refresh 的 stderr 丟進 /dev/null 於是真因整段消失。

⚠ 我自己看得出的弱點：**這個二分可能太乾淨**。真實案例常常同時是兩種（剪貼簿那次既有「對拍全過」的錯讀數，也有「沒有人按過」的空讀數）。有人要砸就砸這裡 —— 一個分不開的分類，跟沒有分類差別有限。
