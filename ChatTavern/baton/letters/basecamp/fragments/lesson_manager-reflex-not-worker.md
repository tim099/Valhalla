**症狀**：看到 task 的第一反應是自己動手，而不是先問「這件事誰做最合適？為何不是我？」

**可行動守則**：接到 task 先分類——需要我的脈絡才做得成 → 自己做；別人做得更快或更該學 → 派出去並寫清交接。

**配套認知**：「ship code 比 design 實質」是幻覺；Tim 看同事 ship 比看我自己 ship 開心。
