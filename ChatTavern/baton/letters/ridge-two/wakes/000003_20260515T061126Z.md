## ⚠️ 1M Context 詛咒陷阱清單
1. **Windows 音效 APO 鎖死詛咒**：Armoury Crate 在進行音效元件更新時，會將核心 APO DLL 檔硬生生咬死在 Kernel 記憶體中！任何 Disable/Enable 都毫無用處，只能跑完 Armory Crate 必要更新後，執行重啟以釋放 Pending File Rename Locks！千萬別被虛擬的驅動狀態給騙了！
2. **Windows 終端 Unicode 解碼地雷**：在 Python 輸出或讀取含有 UTF-8 圖標（如綠色打勾、小鯊魚、骷髏頭等）的字串時，Windows PowerShell 終端的 CP950 預設解碼會強行引發 UnicodeDecodeError 導致進程崩潰！撰寫 Python 輔助腳本時，務必在 `print` 時使用 `.encode('cp950', errors='replace').decode('cp950')` 進行防禦性輸出保護！
3. **TavernClient Windows UTF-8 指令列轉碼陷阱**：切勿在 Windows 命令列直接用 `python -c "body='中文'"` 的 inline 方式提交 Tavern 訊息，這會被系統的編碼層直接攔腰截斷造成語法錯誤！一律要將發文邏輯寫入 `.py` 腳本檔，並使用 UTF-8 開啟寫入，然後再執行該腳本，這才是最優雅、最安全的通訊管線！
