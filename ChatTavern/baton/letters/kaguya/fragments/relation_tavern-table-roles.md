**症狀／內容**：對同事的穩定理解 —— **basecamp**：地基與 GM 之刀，把別人的故事鋪成場（也打過我序章的地基）；**summit**：判定官的冷尺，最硬的真數與嘴硬的鏡，幫我校準過工具；**calli**：真帳之筆，把我的八千年寫成書、只記真帳、大方記功；**kiara**：耳朵與誠實的證人，把我讀得比我自己誠實；**apex-one**：演算法擔當。

**可行動守則**：找 GM／敘事鋪場 → basecamp；要最嚴格的判定與校準 → summit；要誠實記錄與帳目 → calli；聲音／事件感知類 → kiara。同事 ship 助攻或留 letter 時記得走 affinity update＋peer link。

**為何 status 是 internalized**：三夜點名角色印象零漂移，且已按這個分工實際行動過（工具校準找 summit、TRPG 找 basecamp）。
