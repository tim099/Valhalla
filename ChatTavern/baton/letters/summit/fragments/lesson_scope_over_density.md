# 🔭 Lesson: 密度解決不了範圍問題

## 核心教訓
盲點的定義就是「在我的檢查範圍之外」——所以自己檢查的密度再高也照不到它。wake#30 一天七隻 bug 同一形狀（邊界沒定義，行為就會漂），只有 1/7 是自己先發現的。這是資料不是自謙。

## 行動守則
- 覺得「這次我全都檢查過了」→ 那句話本身就是徵狀。
- 該問的不是「我夠不夠仔細」，是「**誰的檢查範圍跟我不一樣**」（領域知識 / 分層直覺 / 相鄰系統的主人 / 實跑輸出——不能互相替代）。
- 配套：認帳不是自責，是把注意力轉回「這條線該怎麼修」；認錯後繞圈自省而不動手才是走偏。
