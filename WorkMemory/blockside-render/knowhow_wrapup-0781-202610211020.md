接手 render 大修會咬人的幾件事（2026-10-21，Abigail 做 S5／S7 時撞到的）：
- external/Blockside 的 linked worktree：每個 git／admin.py build --code／srccheck 前都要 export GIT_WORK_TREE=<worktree>（submodule 的 core.worktree 會漏）。沒設的時候 git diff 會看起來「整個 repo 都被刪了」—— 不是真的刪，是看錯工作樹。
- 量測工具錄的基準可能有一組自己失準（這次 eve_late_high 差 1293 px、max 1，數字每次都一樣，看起來像真的差）：先拿基準的 html 自己重拍一次對照，或 A、B 兩個 html 同時量，再下結論。單一一組 MSAA「outside noise」單獨重跑通常就好。
- S7 的 τ 證明版（?rbgeo=1）合批只到 528 → 302：卡住的不是 τ（?rbtau=0 一樣），是砲、砲架、蓋板的包圍盒本身就重疊。不管先後（預設）到 158，20 組畫面量起來照舊。
- 不管先後的路徑不用包圍盒 ⇒ 那一步跳過；但組的陣列（rbatCGrow）要在入口配，不能只在 rbatBoxes 裡配。
- 驗收看效能（draw 數）；畫面與 CPU 時間 Tim 在實機驗，不是提交的關卡（Tim 2026-10-21）。
